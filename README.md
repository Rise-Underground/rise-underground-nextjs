# RISE Underground

Next.js/React/TypeScript/Tailwind site for RISE Underground -- trackers, leaderboards, and an
almanac.

**New to this project or not a developer?** Start with **[SETUP.md](SETUP.md)** -- a plain-language
walkthrough for installing, running, and deploying the site.

**Working on the code?** See **[`.claude/README.md`](.claude/README.md)** for how the project is
structured, its data-fetching patterns, and coding/design conventions.

## Quick start (developers)

Needs Node 18.18+.

```bash
npm install
npm run dev      # http://localhost:3000
```

```bash
npm run build && npm run start   # production build check before deploying
```

## Status
